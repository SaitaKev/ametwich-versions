# AMETWICH — versions du jeu

Ce dépôt ne contient que les fichiers publiés du jeu AMETWICH, lus par le launcher et par le jeu
pour les mises à jour automatiques :

- `maj.properties` : la version en cours, les adresses et les empreintes des fichiers ;
- `AMETWICH-Client.jar` : le mod AMETWICH ;
- `AMETWICH.mrpack` : le paquet du jeu (Fabric, Fabric API, Simple Voice Chat, mod AMETWICH).

Pour jouer : téléchargez le launcher sur https://ametwich.fr.
